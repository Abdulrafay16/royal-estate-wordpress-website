# Royal Estate - USA Real Estate Website

**Live Demo:** https://royaldrive.page.gd/
**Built With:** WordPress + Elementor + Custom HTML / CSS
**Theme:** Black & White Premium Theme

## About This Project
Royal Estate is a USA-based real estate website designed for users looking to buy or rent houses in the United States.

The website features a clean black & white premium design, easy property search, and direct inquiry for buyers and renters.

## Properties Available In USA
- California
- Texas
- Florida
- New York
- Arizona

## Key Features

### 1. Buy & Rent Properties in USA
- Houses For Sale in USA
- Houses For Rent in USA
- Villas, Apartments & Family Homes

### 2. Advanced Property Search
- Search by State / City
- Filter by Buy or Rent
- Filter by Price Range
- Filter by Bedrooms / Bathrooms

### 3. Property Listing Cards
- Property Image
- Price (Sale Price / Monthly Rent)
- Location - City, State
- Beds, Baths, Area (Sq Ft)

### 4. Property Details Page
- Full Image Gallery
- Property Description
- Features & Amenities
- Location Map
- Agent Contact

### 5. Custom HTML Widgets
- Property Search Filter (Custom HTML + CSS)
- Monthly Rent / Mortgage Calculator
- WhatsApp / Contact Inquiry Button

### 6. Fully Responsive
- 100% Mobile Friendly
- Tablet & Desktop Optimized
